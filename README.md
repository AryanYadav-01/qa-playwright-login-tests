# QA Practice Project — Login Test Automation

Manual and automated test cases for a login form, built to practice core QA skills: test case design, bug documentation, and browser automation.

## What this covers
- 6 test scenarios: valid login, invalid password, invalid username, empty fields
- Manual test case documentation (expected vs actual results)
- Automated with Playwright across Chromium and Firefox — 12/12 tests passing

## Tech used
Playwright, JavaScript, Node.js

## How to run   
npm install
npx playwright test


## Site under test
https://the-internet.herokuapp.com/login
